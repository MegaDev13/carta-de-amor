ESTRUTURA DE ARQUIVOS:
  index.html           → Abrir no navegador
  images/              → Todas as fotos (já incluídas)
  videos/              → video1.mp4, video2.mp4 (já incluídos)
  audio/
    final-message.mp3  → SUBSTITUIR pelo seu áudio de voz

  3. Abra index.html em qualquer navegador
